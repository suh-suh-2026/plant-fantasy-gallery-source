# 식물 판타지 정원

식물과 마법을 주제로 한 영상·이야기 전시 웹사이트입니다. GitHub Pages에서 바로 열 수 있는 정적 사이트로 정리되어 있습니다.

## 사용 방법

`index.html`을 열면 식물 이야기와 영상을 감상할 수 있습니다. 사진·문서·영상을 추가하면 해당 파일은 서버가 아닌 현재 브라우저에만 저장됩니다. 다른 기기나 브라우저에서는 보이지 않으며, 브라우저 데이터를 삭제하면 함께 사라집니다.

## 파일 구성

- `index.html`: 웹사이트 화면과 동작
- `assets/`: 배경 이미지
- `.nojekyll`: GitHub Pages에서 파일을 그대로 공개하기 위한 설정
